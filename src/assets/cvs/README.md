# CV

Dépose ici les deux versions du CV attendues par `assets/data/cvs.json` :

| Fichier attendu | Version |
|---|---|
| `cv-developpeur-angular.pdf` | CV Développeur Front-End / Angular |
| `cv-operations-terrain.pdf` | CV Opérations & Terrain |

Le sélecteur (header + page contact) lit cette liste dans `cvs.json`.
Pour ajouter une troisième version, ajoute une entrée dans ce JSON et dépose
le PDF ici : aucun template à modifier.

Tant que les fichiers sont absents, le sélecteur s'affiche mais les liens
conduisent à une erreur 404.
